# LLM Writing Skills

LLMを使って文章を書く・推敲するための指示書（スキル）集です。禁止語を増やすよりも、文章の目的に合わせた編集手順と、書いた後の点検を重視しています。Issei Matsuzoeが、文章の読み比べと実際の利用を通じて改善していきます。

## 収録スキル

| スキル | 用途 |
| --- | --- |
| [Scientific Writing](skills/scientific-writing/SKILL.md) | 論文・研究レポートの執筆と推敲。対象、条件、主張と根拠の対応を点検します。 |
| [Overleaf Editor](skills/overleaf-editor/SKILL.md) | ブラウザで開いているOverleaf原稿に対し、一意アンカーと全文照合を行いながらキー入力で局所編集を反映します。 |

現在は試作版です。一般ドキュメント用スキルやプラグインは、まだ含めていません。

## 編集で大切にしていること

- **意味を保ち、構成は組み直す。** 元の文順に固執せず、事実や意図を保ったまま読みやすく整えます。
- **何を指すか、その場で分かるようにする。** 比較・計算・最適化などの対象を、元資料に基づいて明示します。
- **文書の目的に合わせる。** 論文と一般文書では、用語の繰り返し、説明順、根拠や留保の扱いを分けます。
- **書くことと、点検することを分ける。** 書き終えた文章に指針を適用し、見落としを確かめます。
- **明確な表現は残す。** 簡潔で十分に意味が通る箇所を、機械的に長く書き換えません。

## 使い方

1. スキルの本文をAIに読み込ませます。スキル対応ツールでは、そのツールの方法で登録・呼び出してください。
2. 原稿または執筆用の資料と、想定読者・目的・変更してよい範囲を渡します。
3. 出力された本文と、必要に応じて別に返される確認事項を読み、採用を判断します。

依頼例：

```text
Scientific Writingの指針に沿って、次の原稿を推敲してください。
想定読者は同分野の研究者です。構成や説明順の変更はできますが、
数式・条件・科学的主張は保ってください。
本文と、著者への確認事項がある場合は、それらを分けて返してください。
```

GitHubのリンクを渡す場合も、AIがリンク先の本文を取得できる必要があります。登録先のスキルは、GitHubを更新するだけでは更新されるとは限りません。

## 判断例と検証

[判断例](skills/scientific-writing/references/examples.md)には、具体化する例と、そのまま残す例を収録しています。例文は説明用に作成した架空の文章で、実際の研究結果や比較実験の出力ではありません。

ファイルの形式やリンクの確認と、文章品質の評価は別です。この初期版について、モデル横断の品質比較や、見落としを防ぐ効果はまだ検証していません。今後は実際の入力・出力・採否の理由・指針の変更を区別して改善します。

非公開の原稿・会話ログ・認証情報は、このリポジトリに含めません。スキルは執筆を支援する指示書であり、科学的内容の妥当性や投稿先の要件を自動で保証するものではありません。
